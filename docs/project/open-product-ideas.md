# Open Product Ideas

Этот документ содержит предварительные продуктовые идеи, которые ещё не являются утверждёнными требованиями.

Базовое описание продукта и системы находится в:

* `docs/product/problem-and-solution.md`
* `docs/architecture/system-overview.md`

Здесь фиксируются только идеи, которые ещё предстоит обсудить и подтвердить.

## Идеи

* Адаптировать напоминания по уходу на основе обратной связи пользователя, а не использовать только фиксированный интервал.
* Использовать простые варианты обратной связи, например: «полил», «почва ещё влажная», «почва сухая».
* Рассмотреть главный экран, построенный вокруг растений, которым требуется внимание сегодня.
* В будущем добавить историю растения.
* В будущем добавить фото-прогресс растения.
* Рассмотреть более глубокую персонализацию ухода на основе истории конкретного растения и условий его содержания.

## Статус

Все пункты выше являются открытыми продуктовым гипотезами.

Перед реализацией каждая идея должна быть отдельно обсуждена и либо:

* перенесена в утверждённую продуктовую документацию;
* превращена в GitHub Issue;
* отклонена и удалена из этого документа.

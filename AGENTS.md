# Инструкции для AI-агентов

## Назначение репозитория

Этот репозиторий хранит глобальную документацию Chloe Care — продукта для помощи в уходе за домашними растениями. Здесь описываются продукт, границы системы, архитектурные решения и договорённости по документации.

Документация, относящаяся к конкретной реализации, должна находиться рядом с кодом в соответствующих репозиториях frontend или backend.

## Перед началом работы

Перед изменением документации прочитайте материалы, относящиеся к задаче:

- `docs/product/problem-and-solution.md` — проблема, ценность и пользовательский сценарий;
- `docs/architecture/system-overview.md` — границы и устройство системы;
- `docs/project/documentation-principles.md` — правила ведения проектной документации;
- `docs/project/open-product-ideas.md` — неутверждённые гипотезы продукта.

## Правила изменений

- Ведите документацию на русском языке. Английский используйте для технических идентификаторов, имён файлов, API и кода.
- Сохраняйте документы краткими, конкретными и актуальными.
- Не выдавайте идеи из `docs/project/open-product-ideas.md` за утверждённые требования.
- Для значимого архитектурного решения с альтернативами создавайте краткий ADR с контекстом, решением и последствиями.
- Не добавляйте в этот репозиторий реализацию frontend, backend или документацию, специфичную для одного из них.
- При изменении фактов о продукте или системе обновляйте связанные документы, если это необходимо для сохранения согласованности.

## Проверка перед завершением

- Убедитесь, что внутренние Markdown-ссылки корректны.
- Проверьте, что заголовки и структура документа соответствуют стилю соседних файлов.
- Явно отмечайте предположения, открытые вопросы и неподтверждённые решения.

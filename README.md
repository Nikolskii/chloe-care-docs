# Chloe Care — документация проекта

Этот репозиторий содержит общую документацию продукта Chloe Care — персонального помощника по уходу за домашними растениями.

Приложение помогает вести коллекцию растений, определять их по фотографии, получать рекомендации по уходу и вовремя проверять необходимость полива. Рекомендации могут адаптироваться к истории ухода и обратной связи пользователя.

## Границы репозитория

Здесь хранится глобальное знание о продукте и архитектуре. Документация, относящаяся к конкретной реализации, находится в репозиториях frontend и backend рядом с кодом.
